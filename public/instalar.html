Instalar MB REFERÊNCIAS

Use o sistema como aplicativo no Android ou no PC. Quando instalado, ele abre em uma janela própria, sem barra de endereço.

Abrir MB REFERÊNCIAS

Se o botão não aparecer

  1. Android (Chrome): abra o menu ⋮ e escolha Instalar app ou Adicionar à tela inicial.
  2. PC (Chrome ou Edge): abra o menu do navegador e escolha Instalar MB REFERÊNCIAS, ou use o ícone de instalação na barra de endereços.
É um aplicativo web instalável, não um APK ou EXE. Para acessar os dados atualizados do Firebase, é necessária conexão com a internet.
