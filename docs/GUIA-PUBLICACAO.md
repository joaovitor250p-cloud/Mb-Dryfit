# Guia de publicação — MB REFERENCIAS 4.15

1. Faça uma cópia de segurança do repositório atual.
2. Substitua os arquivos pelo conteúdo deste pacote.
3. Preserve as credenciais e configurações de conexão já cadastradas no GitHub Actions.
4. Envie os arquivos para a branch `main`.
5. Abra **Actions** e acompanhe o workflow **Publicar MB REFERENCIAS**.
6. Só considere a atualização publicada quando `npm run build` e `deploy` terminarem com sucesso.

## Testes depois da publicação

- Abrir Catálogo, Amostras, Cortes, Ordem de Corte, Gastos, Informações MB e Oficinas.
- Abrir uma foto no notebook e testar os botões de zoom, a roda do mouse e o ajuste à tela.
- Em Amostras, abrir uma OC com 1, 2 e 3 fotos; confirmar a pilha e deslizar para a esquerda/direita para navegar.
- Conferir as setas e os atalhos de teclado na galeria.
- No celular ou notebook com tela sensível ao toque, deslizar entre áreas autorizadas e conferir a animação.
- Trocar de área e voltar; confirmar que pesquisa, filtros e posição da lista são restaurados.
- Conferir a tela de carregamento e a logo MB Dri-Fit.

## Dados e permissões

A versão 4.15 não altera coleções, estrutura de documentos nem regras de acesso. Não é necessário publicar novas regras.
